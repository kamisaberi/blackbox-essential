#### STEP 1: Solidify `libxinfer.so` (Days 1 to 10)
**Goal:** Prove that your C++ shared library can load a model and run inference in < 2ms on CPU/NPU.

1. Create the `xinfer-essential` directory on your Ubuntu VM.
2. Compile `libxinfer.so` using OpenVINO CPU mode (since you are on a VM).
3. Load a simple ONNX anomaly model (or dummy ONNX model) and write a small C++ test (`examples/02_openvino_cpu.cpp`) that feeds a feature array and gets a confidence score.
4. **Deliverable:** A compiled `libxinfer.so` installed in `/usr/local/lib/`.

---

#### STEP 2: Connect `libblackbox.so` to `libxinfer.so` & eBPF (Days 11 to 20)
**Goal:** Build the active defense pipeline linking data ingestion, AI evaluation, and kernel blocking.

1. Create the `blackbox` directory on your Ubuntu VM.
2. Compile `libblackbox.so` linking against `/usr/local/lib/libxinfer.so`.
3. Implement `network_ingest.cpp` (reading raw packets) and `ebpf_blocker.cpp` (executing kernel IP drops).
4. Run an end-to-end test: Pass a packet vector to `libblackbox.so` $\rightarrow$ `libxinfer.so` scores it as `0.92` (Anomaly) $\rightarrow$ `ebpf_blocker` executes `iptables`/eBPF drop.
5. **Deliverable:** A C++ daemon (`blackbox_daemon`) that blocks a simulated attack in real-time.

---

#### STEP 3: Build the "Magic Demo" & Simple Web Feed (Days 21 to 30)
**Goal:** Create a visual demonstration that proves the system works to non-technical stakeholders.

1. Enable the embedded HTTP/WebSocket server in `src/api/websocket.cpp`.
2. Connect `web/index.html` to the WebSocket stream.
3. Record a 2-minute video demo:
   * **Left side of screen:** Terminal sending ping/attack packets to your Ubuntu VM.
   * **Middle of screen:** `blackbox_daemon` log showing `< 1ms` detection and eBPF drop.
   * **Right side of screen:** Web UI flashing red with the blocked IP address instantly.
4. **Deliverable:** A complete, working MVP and video demo.
