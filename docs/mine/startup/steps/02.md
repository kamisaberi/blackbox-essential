### The 6 Essential Parts of the Commercial Final Product

#### 1. The Sentinel Daemon Orchestrator (`sentinel_daemon`)
The main C++ service binary running on the hardware appliance.
* Loads system configurations (`blackbox.json`) and threat rules (`rules.json`).
* Initializes `libblackbox.so` and `libxinfer.so`.
* Monitors hardware sensors (CPU temperature, NPU/GPU usage, memory load) and exposes system health metrics.

#### 2. Authenticated C++ REST API & WebSocket Server
An air-gapped, encrypted (TLS 1.3) C++ HTTP server running inside the appliance.
* **Role-Based Access Control (RBAC):** Login system distinguishing between *Admin* (can change rules), *Analyst* (monitors threats), and *Auditor* (reads logs).
* **REST Endpoints:** `/api/v1/threats`, `/api/v1/blocked-ips`, `/api/v1/system-health`, `/api/v1/rules`.
* **WebSocket Feeds:** Pushes live alerts to the dashboard in under 1 millisecond.

#### 3. Production Air-Gapped Web UI Command Center
A visual dashboard served directly by the appliance's embedded HTTP server.
* **Live Threat Stream:** Flashing alert feed displaying incoming attacks, source IPs, and anomaly scores.
* **1-Click eBPF Management:** Interactive table showing blocked IP addresses with a "Manual Unblock" button.
* **Hardware Telemetry Meters:** Real-time visual gauges showing NPU/GPU utilization, memory usage, and packet rates.
* **Rule Builder UI:** Visual interface allowing security operators to add or adjust threat thresholds without editing JSON files manually.

#### 4. Hardware Licensing & Anti-Piracy Module (`sentinel_license`)
Protects your software from being illegally copied or run on unauthorized hardware.
* Binds your software license to the appliance's **TPM 2.0 chip, motherboard serial, and MAC address**.
* Encrypts the local threat rules and AI models so competitors cannot steal your proprietary detection algorithms.

#### 5. Compliance & Forensic Report Generator
Enterprise and defense clients require audit documentation for compliance.
* Exports encrypted threat logs and mitigation actions into formal **PDF, CSV, or JSON audit reports**.
* Complies with **CMMC (Cybersecurity Maturity Model Certification), ISO 27001, and NIST 800-53** standards.

#### 6. Turnkey Appliance OS & Flashing Installer
Packages the entire operating system, libraries, and web interface into an immutable image.
* Uses **Ubuntu Core or Yocto Linux** to create a read-only, tamper-proof OS image.
* Ships on an installer USB drive that turns any bare-metal 1U server or NVIDIA Jetson / Rockchip board into a plug-and-play Blackbox Sentinel Appliance in 5 minutes.
